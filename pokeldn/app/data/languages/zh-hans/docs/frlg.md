# 火红和叶绿

Switch 版火红和叶绿是在模拟器内运行的原始 GBA ROM，因此叠加了两层连接协议：

| 协议层 | 归属 | 文档位置 |
| --- | --- | --- |
| LDN 和 Pia | 属于模拟器，与其他所有 Switch 游戏共用 | [无线层](ldn.md) |
| GBA 连接：RFU 帧、席位、块发送 | 属于 ROM | 这些页面 |

[pret/pokefirered](https://github.com/pret/pokefirered)是以下位置整个游戏级协议的权威参考：`REVISION >= 0xA`。从两台主机读取的卡带头部信息：软件版本为`0x0A`，游戏代码为`BPRF`（火红，法语）和`BPGF`（叶绿，法语）。主机端也会为英语、德语、意大利语、西班牙语和日语的两个版本选择经过测量的 ROM 与 RAM 地址，共计十二款卡带。玩家在朋友列表中选择 pokeldn 后，神秘礼物会根据卡带代码检测语言；“基本”界面会在版本旁显示该语言。新增语言已进行离线 ROM 和 mGBA 检查。零售版验证覆盖情况列于[零售版验证](frlg_rom_map.md#retail-verification)。参见[卡带布局](frlg_rom_map.md#the-international-revision-0x0a-cartridges).

如果主机在关联约三秒后、Pia 会话完成建立时离开，原因是收到的关联响应未包含 6、9 和 12 Mbit/s（[frlg_link.md](frlg_link.md)，“广播的速率集”）；缺少 Pia 类型 2 Join Response 也会产生相同现象。

## 已实现的功能

在零售版硬件上，主机端支持两款卡带中主机提供的全部活动：双向神秘礼物、主机端和加入端交换、完整联盟交谊厅（包括完整连接对战）、神秘新闻、通信俱乐部竞技场，以及来访的对战塔训练家。

通过礼物连接的两个解释器，主机还能运行发送给它的代码：读写其内存、将其 ROM 映射为对应运行版本的具名函数、以八个参数调用其自身函数，并由其自身的`CreateMon`生成主机端选定的宝可梦，放入玩家的同行队伍。随机数生成器已实现端到端闭环；每次尝试定向遭遇异色宝可梦只需按一次 A。

已解析模拟器客户机与封装程序之间的边界（[在主机上执行代码](frlg_rom.md#where-the-boundary-stands)）：客户机唯一一次越过区域后备存储的写入精确到字节，且写入值为常量；使用植入指针的代码从`main`自身数据的静态地址读取目标；系统调用写入组件的值会被读回为计数和 GBA 地址，每个地址都经过边界检查。封装程序自身的扫描流水线已解析到第一阶段（[封装程序自身的扫描流水线](frlg_rom.md#the-wrappers-own-scan-pipeline)）：扫描结果、消费循环和父节点候选列表均为固定结构且有边界限制，唯一接收长度的路径（站点名称，最多`0x40`）也在调用处限制了长度。
