# 晶灿钻石和明亮珍珠

晶灿钻石和明亮珍珠由 ILCA 使用 Unity 开发，IL2CPP 游戏代码直接运行于 Pia 之上。

测量使用法语版明亮珍珠 1.3.0，场景为联盟交谊厅（宝可梦中心二楼、左侧接待员、普通的“是”选项）和地下大洞窟。
